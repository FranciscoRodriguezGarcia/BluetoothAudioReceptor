# Bluetooth Audio Receptor

Aplicación Windows para recibir audio Bluetooth A2DP de dispositivos compatibles y reproducirlo usando la salida de audio predeterminada del sistema.

El código del MVP se desarrolla en `feature/a2dp-sink-mvp`.

> La Nintendo Switch debe poder actuar como fuente A2DP para emparejarse con Windows. La PS3 no emite el audio general de los juegos por A2DP.
